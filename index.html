🔥 Conectividade em Tempo Real & Firebase Realtime Database

O projeto está integrado à sua instância oficial do Firebase (projeto-urna-eletronica). O sistema conta com uma arquitetura dual ultra-resiliente:

1. Modo Sincronizado Imediato (Ativo)

Funciona instantaneamente entre abas ou janelas abertas no mesmo navegador ou rede local, permitindo que você teste imediatamente todas as telas mesmo sem alterar nada no Firebase.

2. Modo Nuvem Externa (Firebase Realtime Database)

Para conectar o celular através de 4G/redes externas, basta alterar as regras de segurança no Firebase Console para leitura e escrita: 

{
  "rules": {
    ".read": true,
    ".write": true
  }
}
