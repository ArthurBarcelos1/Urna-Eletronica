# Simulador de Votação

Projeto de demonstração com modelos de teste para visor, teclado e terminal.

Abra o projeto por um servidor HTTP local (por exemplo, a extensão Live Server do VS Code) para que a urna possa carregar os dados de `carregamento/candidatos.csv`. Abrir `urna.html` diretamente como arquivo não permite esse carregamento no navegador.
